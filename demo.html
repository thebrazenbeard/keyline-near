Why NEAR matters
NEAR's public view_access_key RPC reveals FullAccess versus FunctionCall permissions, including receiver, method list and gas allowance. The CLI also supports a bounded, read-only public testnet observation.

    
The important caveat
A NEAR gas allowance is not an asset spending limit. Even a key that matches a stated receiver/method policy might call a contract that moves assets. This demo asks for review; it never declares a real transfer safe.

  

  
All five interactive cases are fictional test fixtures. This localhost app has no live API calls, secrets, wallet connection or transaction endpoints. The separate opt-in CLI can inspect a selected public testnet key, but does not authenticate ownership or contract effects.
